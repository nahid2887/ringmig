📊 REQUEST/RESPONSE FLOW

   CLIENT (Listener/Talker)
        │
        ├─ 1. POST /api/users/login/
        │     └─→ JWT Bearer Token
        │
        ├─ 2. POST /api/users/oauth2/token/
        │     ├─ Header: Authorization: Bearer JWT
        │     └─ Body: OAuth2 parameters
        │
        ├─→ OAuth2TokenProxyView
        │   ├─ Validate JWT ✓
        │   ├─ Get User ✓
        │   ├─ Get Profile (Listener/Talker) ✓
        │   └─ Forward to OAuth2 Server ✓
        │
        ├─→ Self-Hosted OAuth2 Server
        │   └─ Returns token response
        │
        ├─→ Enrich with user_info ✓
        │
        └─ 3. RESPONSE (200 OK)
           {
             "access_token": "...",
             "token_type": "Bearer",
             "expires_in": 3600,
             "user_info": {
               "user_id": 123,
               "email": "user@example.com",
               "user_type": "talker",
               "talker_id": 789,
               "talker_name": "John Talker"
             }
           }
